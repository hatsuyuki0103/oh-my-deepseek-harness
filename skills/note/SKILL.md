# Note（会话笔记）

## 定位

把会话中值得跨会话保留的内容落盘：

- 结论/决策/约束（"我们定了 X"）；
- 排雷记录（"Y 方案试过不行，因为 Z"）；
- 关键发现/交接信息。

## 落点

**工作区笔记**：.omx/notepad.md（追加式：时间戳 + 标题 + 要点；保持可读、不无限膨胀）。

## 纪律

- 只记值得记的：一次性信息不记；当前对话内容本身不需要转存；
- 笔记写事实与决策，不写臆测；每条尽量带来源/证据；
- 不动无关文件；追加不覆盖。

## 输出契约

```
## Note Saved

- <标题>
```
