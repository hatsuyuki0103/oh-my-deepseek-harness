# Note（会话笔记）

## 定位

把会话中值得跨会话保留的内容落盘：

- 结论/决策/约束（"我们定了 X"）；
- 排雷记录（"Y 方案试过不行，因为 Z"）；
- 关键发现/交接信息。

## 落点（按内容选）

1. **工作区笔记**：.omx/notepad.md（追加式：时间戳 + 标题 + 要点；保持可读、不无限膨胀）；
2. **项目记忆库**：`hindsight_ingest_document`（标题 + 内容）——适合设计决策、调研结论、可复用的发现；记忆服务未配置（401/无 key）时注明并退回 .omx/notepad.md；
3. **纠错记忆**：验证到旧记忆是错的 → ingest 标题「Correction: <主题>」，写明旧说法、事实、证据（新事实自动覆盖旧记忆）。

## 纪律

- 只记值得记的：一次性信息不记；当前对话内容不需要记（会话结束会自动入库）；
- 笔记写事实与决策，不写臆测；每条尽量带来源/证据；
- 不动无关文件；追加不覆盖。

## 输出契约

```
## Note Saved

- <落点 1> — <标题>
- <落点 2> — ...
```
