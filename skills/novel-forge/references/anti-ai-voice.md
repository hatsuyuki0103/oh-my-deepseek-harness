# 反 AI 腔手册（机器层 + 语义层）

> 目标不是「让分数好看」，而是**让读者看不出是 AI 写的**。本手册分两层：**机器层**可复跑、可比较、进门槛；**语义层**由 LLM 按 rubric 审校，补机器管不到的意图/声音/潜台词。两层都过才算交稿。

## 1. 为什么这一层是门禁

- 机器层把「AI 味」变成**可复跑证据**：同一段文本重复扫描得到同一个 `hitsPer1000` / `score`，改动前后能对比，能进章门禁。
- 机器层用**人类负控**做反向约束（≥2 段公认的人类优秀散文，每段 `score ≥ 70` 且 `strongHits = 0`）：阈值过严会误杀好文，这一步专门抓误杀。
- 语义层补机器判不了的东西：潜台词、意象新鲜度、叙述者声音是否稳定。**机器分高 ≠ 交稿通过**；机器分只是下限。

**铁律**：不达标不交稿；改的是正文，不是词表。引擎默认词表**禁止静默修改**（三步调参出口见 §9）。

## 2. 机器层词表全表

机器命中分六类：**强信号**（权重 1.0）、**弱信号**（权重 0.25）、**`style.forbiddenWords`**（权重 1.0，项目自定义）、**句式模板**、**翻译腔正则**、**情绪直给**、**段末升华**。后四类独立计数，不进加权命中。词表为**子串/正则匹配**（不区分大小写；英文按词边界）。

### 2.1 强信号（内置 30 条，单条权重 1.0）

### 2.2 弱信号（内置 12 条，单条权重 0.25）

高频但本身不算错；**密度**才是问题（默认 `maxWeightedClichesPer1000 = 1.5`）。所以弱信号允许少量存在，成片出现时靠频率扣分。

| # | 词 | 使用边界 |
|---|---|---|
| 1 | 突然 | 一段最多一次；连续两段出现应换句法 |
| 2 | 忽然 | 同上，且与「突然」别混用 |
| 3 | 瞬间 | 慎用「的一瞬间」式状语 |
| 4 | 仿佛 | 比喻加速器；一段一次已是上限 |
| 5 | 似乎 | 叙述者不确定时可用，但别拿来回避写实 |
| 6 | 某种 | 名词前占位符，通常意味着没想出具体是什么 |
| 7 | 意识到 | 心理动词；改成动作或对白更自然 |
| 8 | 缓缓 | 与「轻轻/微微」并称三件套 |
| 9 | 轻轻 | 同上 |
| 10 | 微微 | 同上 |
| 11 | 不由得 | 作者解释人物失控，可删 |
| 12 | 忍不住 | 同上 |

### 2.3 句式模板（内置 10 条）

整句结构套话，出现即独立计数（`templateHits`），默认超过 3 条触发 `VOICE-003`。

| # | 模板 | 变体/正则要点 | 人类替代 |
|---|---|---|---|
| 1 | 不是……而是…… | `不是[^。！？\n]{1,40}而是` | 直接说后项，前项用动作否定 |
| 2 | 不仅……而且…… | `不仅[^。！？\n]{1,40}而且` | 拆成两句，第二句给证据 |
| 3 | 与此同时 | 段落转场套话 | 写时间/地点的具体切换 |
| 4 | 这一刻 | 情绪放大器 | 用「他抬手看表」等具体时间标记 |
| 5 | 就在这时 | 廉价转折 | 让转折由人物动作引发 |
| 6 | 仿佛整个世界 | `仿佛整个世界[^。！？\n]{0,12}` | 缩小到一个具体感官 |
| 7 | 是的， | 叙述者应答腔 | 删 |
| 8 | 换句话说 | 论文腔 | 删；或改成人物台词里的「说白了吧」 |
| 9 | 总而言之 | 同上 | 删 |
| 10 | 值得一提的是 | 同上 | 删 |

### 2.4 翻译腔正则（内置 6 条）

英文句法直译进中文的痕迹，独立计数 `translationese`，`≥ 2` 触发 `VOICE-009`。

| # | 正则（示意） | 命中示例 | 改写 |
|---|---|---|---|
| 1 | `作为一个[^，。！？\n]{1,16}[，,]` | 作为一个警察，他…… | 他是警察，他……／当警察这些年，他…… |
| 2 | `当[^。！？\n]{1,40}的时候` | 当他推开门的时候 | 他推开门，…… |
| 3 | `[^。！？\n]{1,20}之一` | 最危险的人之一 | 在危险名单上排第三 |
| 4 | `在[^。！？\n]{1,20}(?:的情况|的条件|的时候)下` | 在这种情况下 | 这样／事情到这一步 |
| 5 | `对于[^。！？\n]{1,16}(?:来说|而言)` | 对于林烬来说 | 林烬……／对林烬，…… |
| 6 | `(?:这|那)是(?:一个|一种)[^。！？\n]{1,24}的(?:方式|过程|结果|方法)` | 这是一种有效的方法 | 这办法管用 |

### 2.5 情绪直给（12 词 + 4 引导词）

情绪被**直接命名**而不是被呈现。`emotionPer1000` 默认阈值 1.2（每千字最多 1.2 次）。

- 12 个情绪词：**愤怒、悲伤、恐惧、激动、震惊、绝望、痛苦、兴奋、紧张、愧疚、焦虑、厌恶**。
- 4 个引导词：**感到、涌上、充斥、袭来**——`emotionGuides` 仅作**人工改写提示**，**引擎不计入** `emotionPer1000`（`analyzeVoice` 只统计 12 个情绪词的出现次数；v1.5 已删该死代码，评分公式不变）。
- 人类写法：把情绪换成**可观察的行为、身体细节、决策偏差**。例：不写「他感到恐惧」，写「他把车钥匙插了三次才插进锁孔」。

### 2.6 段末升华（7 条模式）

段落或章节收尾处强行拔高、预告命运、给读者「回味」。独立计数 `summaryEndings`，`≥ 3` 触发 `VOICE-008`。

| # | 模式 | 典型写法 |
|---|---|---|
| 1 | 一切才刚开始 | 「……而这，只是开始。」 |
| 2 | 命运齿轮 | 「命运的齿轮，开始转动。」 |
| 3 | 一切都变了 | 「……一切，都将不同。」 |
| 4 | 他不知道的是 | 「他不知道的是，门外那个人已经等了十年。」 |
| 5 | 仅仅是……的开始 | 「而这，仅仅是噩梦的开始。」 |
| 6 | 多年以后 | 「多年以后，他会想起这个雨夜。」 |
| 7 | 直到……才明白 | 「直到很多年后，他才明白这笑的意思。」 |

**替代**：把预告换成**当场可见的后果**；把回望换成**人物当下的选择**。段末留白靠删，不靠升华。

### 2.7 英文项目（`lang: en`，各 ≥10 条）

公式与阈值同上；英文项目用独立词表，不与中文混扫。

| 类 | 词表 |
|---|---|
| 强信号（12） | `delve`、`tapestry`、`testament to`、`a mix of`、`little did`、`in the ever-evolving`、`shiver down (his|her) spine`、`heart sank`、`time seemed to stand still`、`the air was thick with`、`let out a breath (he|she) didn't know`、`a ghost of a smile` |
| 弱信号（12） | `suddenly`、`just then`、`somehow`、`seemed to`、`a sense of`、`at that moment`、`couldn't help`、`felt a pang`、`slowly`、`gently`、`barely`、`almost imperceptibly` |
| 句式模板（11） | `not just … but`、`on the one hand … on the other`、`little did … know`、`if … then`、`this is not …`、`it was then that`、`at the end of the day`、`in other words`、`all in all`、`what's more`、`it goes without saying` |

### 2.8 项目词表扩充：`style.forbiddenWords`

```json
{ "style": { "forbiddenWords": ["红唇微启", "倾城一笑", "倒吸一口凉气"] } }
```

- 命中权重 **1.0**（与强信号同权），计入 `forbiddenHits` 与 `weightedHits`。
- 只增不减：**不能**用它把内置词表里的词「去掉」；要降低某类误报走阈值或豁免（§9）。
- 适用场景：本书反复出现的、作者明知是套话却容易顺手写下的词；把写作中「被自己抓到三次以上」的词收进来。

## 3. 评分公式（冻结）

### 3.1 字段定义

| 字段 | 定义 |
|---|---|
| `unit` | CJK 字符数 + 拉丁单词数（与 DOC-007 字数同口径） |
| `strongHits` | 强信号命中次数（每条短语每出现一次计 1） |
| `weakHits` | 弱信号命中次数 |
| `forbiddenHits` | `style.forbiddenWords` 命中次数 |
| `templateHits` | 句式模板命中次数（独立） |
| `translationese` | 翻译腔正则命中次数（独立） |
| `summaryEndings` | 段末升华命中次数（独立） |
| `emotionPer1000` | `emotion 命中次数 / unit * 1000` |
| `hitsPer1000` | `(strong + weak + forbidden) / unit * 1000`（**不加权**，用于展示） |
| `weightedHits` | `strong + weak * 0.25 + forbidden` |
| `weightedHitsPer1000` | `weightedHits / unit * 1000`（**VOICE-002 用这个**） |
| `rhythmCV` | 句长变异系数（句长标准差 / 均值）；`unit < 500` 时为 `null` |
| `paragraphCV` | 段长变异系数；`unit < 500` 时为 `null` |
| `meanSentenceLen` | 平均句长（CJK 字符 + 拉丁词） |
| `tagRatio` / `tagTotal` / `topTag` | 对话标签（`说道/问道/笑道/答道/喊道/喝道/接话` 等）top 占比、总标签数、top 标签词 |
| `lineRefs` | 命中位置：`[{line, phrase, kind}]`，`kind ∈ strong|weak|forbidden|template|translationese|emotion|summary` |
| `skipped` | 被跳过的分析项：短文本时为 `["rhythm","paragraph"]` |

### 3.2 公式（`score` 四舍五入取整，clamp 0-100）

```
score = 100
  - min(45, weightedHitsPer1000 * 12)
  - min(15, templateHits * 3)
  - (rhythmCV === null ? 0 : rhythmCV < minSentenceLengthCV ? 10
                       : rhythmCV < minSentenceLengthCV + 0.10 ? 5 : 0)
  - min(10, emotionPer1000 * 4)
  - min(10, translationese * 3)
  - min(10, summaryEndings * 2)
```

`minSentenceLengthCV` 默认 **0.35**（`project.json.style.thresholds.minSentenceLengthCV`）。

### 3.3 计算示例（自洽）

| 输入 | 值 |
|---|---|
| `unit` | 4000 |
| `strongHits` / `weakHits` / `forbiddenHits` | 1 / 9 / 0 |
| `weightedHits` | 1 + 9×0.25 = 3.25 |
| `weightedHitsPer1000` | 3.25 / 4000 × 1000 = 0.8125 |
| `templateHits` | 1 |
| `rhythmCV` | 0.42 |
| `emotionPer1000` | 0.5 |
| `translationese` / `summaryEndings` | 1 / 0 |

```
100 − min(45, 9.75) − min(15, 3)
    − (0.42 < 0.35 ? 10 : 0.42 < 0.45 ? 5 : 0)
    − min(10, 2) − min(10, 3) − 0
  = 100 − 9.75 − 3 − 5 − 2 − 3 = 77.25 → 77
```

### 3.4 短文本规则（`unit < 500`）

- `rhythmCV = paragraphCV = null`；
- 节奏/段落两项扣分按 **0** 计；
- `skipped: ["rhythm","paragraph"]`；
- 其余项照算（不含短文本豁免的强信号扣分）。

理由：统计样本不足时 CV 不可信，不能让「试写 300 字」被统计噪音判死；同时强信号是绝对命中，与样本量无关。

### 3.5 实现口径（文档 ↔ 引擎一致性）

1. 文本先归一化行尾（`\r\n|\r → \n`），再去 frontmatter；
2. 分句：按 `。！？…`（连续标点算一处）与换行切；分句后剔除纯空白；
3. 段：按空行切；
4. CJK 字符按 Unicode Han 区统计，拉丁单词按 `/[A-Za-z]+(?:['’-][A-Za-z]+)*/g` 统计（**不含数字**，与引擎逐字一致）；例：`R2D2` 计 **2** 个 unit（`R`、`D`），`don't` 计 **1** 个 unit；
5. 词表匹配为**子串**匹配（英文按词边界），同一短语在同句重复出现按出现次数计；
6. 命中位置记录正文行号（不含 frontmatter 行号偏移）。

> 引擎与文档的对应关系：`analyzeVoice()` 返回本手册 §3.1 全部字段；`prose` 命令只跑机器层 + `VOICE-001`。文档不写「引擎没实现」的字段。

### 3.6 异常与英文口径（v1.7 补）

- **fail-closed（修 B2-F2）**：`analyzeVoice` 内部异常时**不得**返回满分，也不得抛异常；必须返回 `score = 0`（保留 `error` 信息），并由调用方产出 **`VOICE-011` MAJOR**（message 注明「语音分析失败，按 0 分处理」）。宁可拦门禁，也不静默放行。
- **英文口径（`lang: en`）**：强/弱/模板/翻译腔词表可用，但 `VOICE-006`（对话标签）、`VOICE-007`（情绪直给）、`VOICE-008`（段末升华）、`VOICE-009`（翻译腔）的英文词表/正则**尚不完整**（登记 v1.1 follow-up）——英文项目这四类可能漏报，**不得**据此宣称「英文同等精度」；英文稿件仍需人工过语义 rubric。

## 4. 机器层规则逐条（VOICE-001…011）

级别缩写见 `logic-rules.md` 表头；此处给阈值与修复策略。规则面冻结：无项目上下文时**只有这 11 条 + 结构三条**可能出现。

| ID | 级别 | 阈值/判据 | 修复策略 |
|---|---|---|---|
| VOICE-001 | BLOCKER | 正文含 `[说明]`、`（注：`、`【写作`、`TODO`、`作者按`、`[AI addition` | 删元信息；确需说明写进 `reports/` 或项目笔记，正文零元信息 |
| VOICE-002 | MAJOR | `weightedHitsPer1000 > 1.5` | 按 `lineRefs.kind=strong/weak` 逐条定点改写；先删强信号，再降弱信号密度 |
| VOICE-003 | MINOR | `templateHits > 3` | 拆模板句；一段最多保留一个转折结构 |
| VOICE-004 | MINOR | `rhythmCV !== null && < 0.35` | 长短句交替：连续 3 句同长度就打断；短句放动作，长句放环境 |
| VOICE-005 | NIT | `paragraphCV !== null && < 0.30` | 段落长度参差：允许单句成段，但不要每段都三行 |
| VOICE-006 | MINOR | `tagRatio > 0.7 && tagTotal ≥ 6` | 标签多样化：动作+对白、省略标签、用停顿代替「说道」 |
| VOICE-007 | MINOR | `emotionPer1000 > 1.2` | 情绪改呈现（动作/身体/选择），删直给词 |
| VOICE-008 | MINOR | `summaryEndings ≥ 3` | 删段末升华，改为当场后果或留白 |
| VOICE-009 | MINOR | `translationese ≥ 2` | 按 §2.4 对照表去英语句法 |
| VOICE-010 | INFO | 非 POV 角色句中含 心想/心里/暗想/暗自（`viewpoint.character` 非空时） | 删越界心理，或改第三人称外部视角（表情/动作/台词） |
| VOICE-011 | MAJOR | `score < minVoiceScore`（默认 60） | 先看扣分大头（陈词 vs 节奏 vs 模板），按最大项改，改后重扫 |

**门禁语义**：`VOICE-002` 与 `VOICE-011` 是 MAJOR，默认拦门禁；`--strict` 下也**不可豁免**（豁免只对可协商的 MINOR/NIT 开放，且必须写 reason）。

## 5. 语义层 7 条 rubric（LLM 审校）

机器层管「像不像套路」，语义层管「像不像人」。每章写完后由审校轮次逐条过；结论写进 `reports/semantic-review-ch-XXX.md`（含每条证据段号与裁定）。

| # | rubric | 判定问题 | 通过标准 | 失败信号 |
|---|---|---|---|---|
| 1 | 叙述者声音一致性 | 全章叙述口吻是否同一个人的？ | 句法偏好、比喻取材、评价尺度前后一致；POV 越界为零 | 前半冷硬后半抒情；忽然出现论文腔 |
| 2 | 意象具体性 | 关键意象能否被拍出来？ | 每个核心场景至少有 1 个可拍摄的具体物件/动作；比喻取材于人物经验 | 全是「空气/光/寒意」这类抽象物；比喻通用 |
| 3 | 情绪呈现 | 情绪是被表演还是被命名？ | 主要情绪转折点靠行为/身体/决策呈现 | 直接写「他很难过/愤怒」；情绪与动作脱节 |
| 4 | 对白潜台词 | 台词是否在说真话之外的东西？ | 至少一半关键对白存在「说的≠想的」；信息不对称可见 | 台词只负责交代设定；人人直言不讳 |
| 5 | 节奏服务场景 | 长短句/段落切分是否配合张力？ | 动作段句短，沉思段句长；紧张处段落变短 | 全篇一种节奏；高潮段落比铺垫还长 |
| 6 | 信息密度 | 每段是否推进？ | 每段至少提供新信息/新变化；无重复交代 | 重复已知信息；大段解释读者已知内容 |
| 7 | 陈词个人化 | 套路是否被写成「这个人物专属」？ | 至少 3 处常见套路有本书专属细节改写 | 通用青春疼痛句、通用狠话 |

## 6. 改写协议（保留事实、只改表达、改后重扫）

规范化改法，防止「越改越错」和「改完不复扫」。

1. **锁事实**：先列出本章**不能变**的内容——发生了什么、谁知道了什么、道具与伤势变化、伏笔埋/收。改写只动表达，不动事实；要动事实 → 改 frontmatter 并重跑六维闸。
2. **读命中**：把 `prose` / `lint` 的 `lineRefs` 抄成清单（行号 + 短语 + kind），逐条决定「删/换/具体化/动作化」。
3. **先删后改**：能删的套话直接删（多数「心中一沉」删掉后句子更好）；必须保留情绪的，换成身体反应或决策偏差。
4. **局部重写 ≤3 段**：一次只改一组连续段落；不要整章重写（会把已过门的场景标注改脏）。
5. **重扫留证**：改完立刻重跑同一命令，记录前后 `score` / `weightedHitsPer1000` / `strongHits`；报告里贴命令 + 数字，禁止只说「已改好」。
6. **回写一致性**：若改写改变了场景事实（谁在场、谁见过什么），同步 frontmatter 并重跑 `lint`；只改正文不改标注 = 下一章门禁必红。

**反例（无效改写）**：把「嘴角勾起」换成「嘴角弯起」——机器词表过了，读者仍然读到同一个套路。词表是**下限**，不是通行证；语义层 rubric 7 会判。

## 7. 「AI 腔 → 改写后」对照（4 组）

**after**

```text
雨下到后半夜。三号仓的门没锁，铁皮上凝着水，指一按就滑。林烬侧身进去。霉味从缆绳堆里扑出来，潮得发闷。他数了三排货架，第三排后面空出一块地，地上一圈干了的印子，圆的，像放过一只桶。他没开手电，先听了十秒。头顶有水滴落进积水，隔四秒一声。角落里那声轻响，是铁皮被风掀了一下，他没回头。
```

### 组 2 · 情绪场景（亲人）

**before**（AI 腔标记举例：心中一沉 / 心中五味杂陈 / 百感交集 / 深吸一口气 / 说不清道不明 / 这一刻 / 意识到 / 仿佛 / 悲伤 / 愧疚；引擎实测 `strong=5` / `template=1` / `emotion=2`）

**after**

```text
电话是七点来的。他听完，说了一句「我知道了」，然后去阳台把昨天晾的衣服收了。收完才发现袜子只收了一只，另一只还在晾衣绳上，夹子没松。他站了一会儿，把那只袜子取下来，捏在手里，捏得指节发白。厨房的水开了，他回去关了火，回来接着站着。袜子还是湿的。
```

**改了什么**：情绪全部转成行为（收衣服、只收一只、关火、站着）；重复动作「还是湿的」承担时间流逝与无处安放；删掉比喻与「仿佛昨天」。

### 组 3 · 对话场景（审讯）

**before**（AI 腔标记举例：语气不容置疑 / 似笑非笑 / 嘴角勾起 / 勾起一抹 / 意味深长 / 目光深邃 / 眼底闪过 / 闪过一丝 / 空气仿佛安静下来；模板：这一刻；弱信号：仿佛 ×2；引擎实测 `strong=9` / `template=1` / `weak=2`）

```text
「你昨晚去了哪里？」林烬的语气不容置疑。
徐岸似笑非笑地看着他，嘴角勾起一抹意味深长的弧度：「我哪儿也没去。」
「是吗？」林烬目光深邃，仿佛要把他看穿。这一刻，空气仿佛安静下来。徐岸眼底闪过一丝慌乱，随即又恢复了镇定。
「是的。」徐岸说道。
```

**after**

```text
「昨晚。」林烬把烟盒放在桌上，推到徐岸手边，「哪儿。」
徐岸抽了一支，没点，在指间转了半圈。「家里。」
「家里哪儿。」
「沙发上。」
「沙发朝哪边。」林烬把打火机递过去，「你坐窗那边还是门那边。」
徐岸接打火机的手停在半空。停了一瞬，他把烟放回桌上。「记不清了。」
```

**改了什么**：审问变成可验的具体追问（沙发朝向），压迫感来自问题结构而非形容词；「慌乱—镇定」的叙述改成「手停了一下，把烟放回桌上」；不写谁说，靠动作区分说话人。

### 组 4 · 开头环境描写（翻译腔治理）

**before**（AI 腔标记举例：作为一个…… / 当……的时候 / ……之一 / 在这种情况下 / 对于……来说 / 这是一种……的方式；弱信号：仿佛 / 某种 / 微微 / 缓缓；引擎实测 `strong=0` / `translationese=5` / `weak=4`——本组的病在翻译腔，不在陈词）

```text
作为一个老刑警，对于林烬来说，这座城市最危险的地方之一就是港区。当他走进三号仓的时候，天还没有亮。在这种情况下，他必须保持警惕。雨水顺着屋檐落下，仿佛某种节奏。他缓缓地走着，微微抬起头，这是一种观察周围环境的方式。
```

**after**

```text
林烬在港区干了十一年。港区有三种人：搬货的、守夜的、还有半夜来搬货的人。他推开仓门，雨声先漏进来，接着是柴油味。屋檐水一线一线落，落在铁皮棚上，不分点。他没急着走进去，站在门口把能看见的东西看完，才抬脚。做了十一年，他习惯先站三十秒。
```

**改了什么**：删掉英语句法（「作为……对于……来说」「当……的时候」「在这种情况下」「这是……的方式」）；把「必须保持警惕」换成可观察的习惯；「仿佛某种节奏」换成「不分点」的具体声音。

| `maxEmotionPer1000` | 1.2 | VOICE-007 | 容忍直给 | 收紧 |
| `minVoiceScore` | 60 | VOICE-011 | 放宽总分门槛 | 收紧 |

> 调阈值 = **对本书文体的适配**，不是免死金牌。硬汉派短句、古典白话、诗化散文各有自己的节奏基线，允许调；但每次调整都要写原因与负控证据。

### 9.2 三步出口（顺序不可跳）

1. **调阈值**：改 `project.json.style.thresholds`，在 `reports/style-tuning.md` 记「改哪个键、从多少到多少、为什么、影响哪条规则」。
2. **写豁免**：`reports/exemptions.json`，`reason` **必填**；`--strict` 下 BLOCKER/MAJOR 不可豁免（VOICE-002 / VOICE-011 属 MAJOR，strict 下无法用豁免混过）。
3. **报用户裁定**：仍误报（尤其人类负控不达标）→ 把样本、分数、命中位置交给用户/Lead 裁定。**禁止**静默修改引擎默认词表。

### 9.3 文体基线建议（起点值，需负控验证）

| 文体 | `maxWeightedClichesPer1000` | `minSentenceLengthCV` | `maxDialogueTagRatio` | 说明 |
|---|---|---|---|---|
| 冷硬悬疑 / 硬汉派 | 1.5（与默认持平） | 0.30 | 0.75 | 短句多，节奏 CV 天然偏低，适度放宽节奏项 |
| 网文爽文 / 都市 | 1.8 | 0.33 | 0.80 | 高频对话，弱信号词密度天然高，陈词项放宽 |
| 文学向 / 生活流 | 1.2 | 0.38 | 0.60 | 陈词容忍度低，句式和标签项更严 |
| 古风 / 武侠 | 1.5 | 0.32 | 0.70 | 四字句多，别把「缓缓」这类词全判死 |

> 表内为**起点建议**，不是硬编码默认；项目默认 1.5。**真实人类语料基线校准**（≥20 段、多文体）登记为 v1.1 follow-up，校准后替换本表。

### 9.4 调参记录模板

```markdown
# 文体阈值调参
- 日期：2026-10-29
- 触发：人类负控样本 2 命中 VOICE-004（rhythmCV 0.31 < 0.35），人工确认文风成立
- 调整：minSentenceLengthCV 0.35 → 0.30
- 理由：冷硬派短句为主，原文节奏 CV 基线 0.31；负控复跑后 score 78、strongHits 0
- 回滚条件：若后续章节出现「全篇同长句」，人工 review 复核
```

## 10. 常见误判与处理

| 现象 | 原因 | 处理 |
|---|---|---|
| 短章命中节奏项 | 样本 < 500 字 | 不应发生：`rhythmCV` 为 `null` 时该项不判；若发生按引擎 bug 报 Lead |
| 对白里的「突然」被计数 | 弱信号是子串匹配，台词不豁免 | 少量可接受（权重 0.25）；密度高就改台词；不要为它加豁免堆积 |
| 古风词被强信号误伤 | 词表是通用 AI 腔，不是文体词表 | 用豁免（reason 必填）或改句式；**不**改引擎词表 |
| 人类负控不达标 | 阈值对该文体过严 | 走 §9 三步，先调阈值并留记录 |
| 改写后分数没升 | 只换了词，句子结构没变 | 按 §6 第 3 步「先删后改」；检查是否仍有模板句 |
| 整章重写后场景标注全错 | 改了事实没改 frontmatter | 重跑六维闸；按 `logic-rules.md` 修 |
